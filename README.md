# Lemus Landscaping

Responsive one-page website redesign for Lemus Landscaping Contractors Inc., Hamilton, Ontario.

## Preview

Open `index.html` locally, or serve the repository root using a static web server. All images, CSS and JavaScript are local. No build step is required.

## Handover

The administrator guides are in `docs/`, including the original-site audit, Wix Editor rebuild instructions, and hosting/form connection requirements.

The existing website uses Wix Editor. This code can be uploaded to Wix Headless as a separate project, or reproduced in the original Wix editor. It is not a direct HTML import into the current editor site.

The contact form currently opens a clearly labelled email draft. Direct delivery needs a tested HTTPS endpoint configured in `config.js`, or a native Wix form when rebuilding in the editor. The booking page currently has no bookable services.

JavaScript syntax, local assets, anchors and original form fields were checked. Desktop previews were rendered and visually reviewed; browser/device tests and live form delivery remain outstanding.
