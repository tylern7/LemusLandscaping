# Rebuild within the existing Wix Editor site

Use this route if the owner wants to keep their existing Wix Editor project and dashboard. Raw HTML/CSS cannot be imported as a native editable replacement page. A full-page iframe is not equivalent and is not the recommended solution for mobile navigation, SEO or native form delivery.

1. Duplicate/back up the current site before editing. Keep the old version available for rollback.
2. Use the watermarked desktop approval preview as the design reference and website/index.html as the copy/structure reference. Upload the local assets to Wix Media Manager, subject to the owner's image rights.
3. Apply forest #193B2C, cream #F6F5EE and leaf #D7E8A8. Use a Georgia-like serif for large headings and a clean sans-serif for body copy.
4. Build anchored sections: Home, Our story, Services, Our work, Reviews and Contact. Use a pinned header and mobile menu. Keep readable text and 44px+ touch targets.
5. Create three service cards with expandable detail text. Build a collapsed project gallery with the original before/after pairs and process photographs. All copy and assets are supplied in the source.
6. Retain or recreate the native Wix contact form: Name required/max100, Email required/max250, Subject optional, Message optional. Match the original placeholders and Send label. Use the existing form if possible, so submissions and automation configuration are retained. If replacing it, reconnect its submission table/notifications, success message and owner-approved recipients.
7. In the dashboard, confirm the correct Forms & Submissions destination. Under Automations, confirm who receives enquiry notifications. The public contact email is not proof of the current automation recipient.
8. Keep /book-online while it has no services. Show an availability-check link, not a promise of immediate booking. If booking services are later added, verify the full selection and confirmation journey.
9. Maintain phone, email, Google and Facebook links. Configure /aboutus, /services and /cotact redirects to the matching one-page anchors if those old pages are removed. Verify redirects in the chosen Wix editor/version.
10. Review desktop, tablet and mobile versions before publishing. Send an owner-authorized test enquiry and confirm it appears in the submissions dashboard and correct inbox. Do not publish a decorative form with no working submission connection.
